## 1. 背景・目的

### 1.1 現状の業務フロー
1. iPhone で患者を撮影（正面・斜め・あおり・横顔）
2. Meitu（美図秀秀）を開き、写真を4枚取り込む
3. 4分割テンプレートを選び、各枠に配置・拡大縮小・位置調整
   - 顔全体が映ること（頭頂部〜顎先が完全に入る）
4. モニターによっては目元をぼかす
5. 書き出し・保存 → テレビに横長で映す

### 1.2 課題
- 汎用アプリのため、毎回テンプレート選択・配置・サイズ調整を手作業で行っている
- 作業のたびに顔の大きさ・位置がばらつく
- 患者の医療写真を外部サービスのアプリで扱っている（個人情報・プライバシー上のリスク）
- ぼかし処理も手作業

### 1.3 目的
**「4枚選ぶ → 自動で整った4分割画像ができる → 必要なら目元ぼかし → 保存」までを、iPhone 上の専用アプリで短時間・均一品質で行えるようにする。**

## 3. 前提条件（ヒアリング結果）

| 項目 | 決定内容 |
|---|---|
| 利用端末 | iPhone 1台のみ |
| Apple Developer Program | 未加入 |
| 出力の用途 | テレビに横長で映す |
| 出力サイズ | **16:9（3840 × 2160 / 4K）を標準**。3:2（4800 × 3200）も選択可 |
| 文字入れ | 不要 |
| ぼかし | 目元のみ・ブラー（モザイクではない）・横顔も対象 |
| 写真の向き | 加工しない（左右どちら向きでもそのまま使う） |
| 配置 | **位置固定**: 左上=正面 / 右上=斜め / 左下=あおり / 右下=横顔。枠ごとに写真を選ぶ |
| 配布方式 | **Web アプリ**（Safari で開き、ホーム画面に追加して使う） |

> 16:9 を標準にする理由: テレビの画面比率と同じため、上下に黒帯が出ず画面いっぱいに表示できる。各セルは 1920 × 1080（フルHD）になり、テレビ表示には十分な解像度。

## 4. スコープ

### 4.1 対象範囲（MVP）
- 写真ライブラリから4枚を選択
- 2×2 テンプレートへの自動配置（顔検出による自動トリミング）
- 手動微調整（拡大縮小・移動・傾き補正）
- 目元ブラーの自動付与（ON/OFF 切替、手動補正可）
- 写真ライブラリへの保存・共有

### 4.2 対象外（将来検討）
- 顔の向きの自動判定・左右反転
- アプリ内撮影（顔位置ガイド付きカメラ）
- 術前/術後（ビフォーアフター）比較レイアウト
- 文字入れ
- 複数端末・複数スタッフ対応、クラウド保存

## 5. 機能要件

### F-01 写真選択と割当
- 4つの枠（正面 / 斜め / あおり / 横顔）をそれぞれタップして、写真ライブラリから1枚ずつ選ぶ
- 選んだ写真は位置固定の枠に入る（左上=正面 / 右上=斜め / 左下=あおり / 右下=横顔）
- 枠をもう一度タップすると写真を選び直せる
- 写真の向きは加工しない（左右反転・回転なし）

### F-02 テンプレート
- 2×2 グリッド固定。左上=正面 / 右上=斜め / 左下=あおり / 右下=横顔
- 出力比率: 16:9（標準）/ 3:2 を切替
- 区切り線なし・背景黒（初期値）
- 背景は真っ黒に処理する（シャドウのみ締める。顔の明るさは変えず、白飛びを増やさない）

### F-03 自動配置（本アプリの核）
- 顔を検出し、各セル内に以下のルールで配置
  - 頭頂部〜顎先が完全に収まる（サンプル同様、首元まで入る程度）
  - 4枚で顔の大きさがそろうよう拡大縮小
  - 顔の中心をセル中央付近に配置
- 横顔・あおりで検出が不安定な場合は、人物の輪郭検出で補う。それでも失敗したら中央配置にして手動調整を促す
- はみ出して余白が出る部分は黒で埋める

### F-04 手動微調整
- セルをタップして選択 → ピンチで拡大縮小、ドラッグで移動
- 「自動配置に戻す」ボタン

### F-05 目元ブラー
- 全体で ON/OFF をワンタップ切替（セル単位でも切替可）
- 顔の特徴点から目の位置を検出し、目元にブラーを自動付与
- 横顔は片目のみ。検出精度が下がりやすいため、**ブラー位置をドラッグで動かせる・タップで追加/削除できる**ようにする
- ブラーの強さ・範囲の大きさを調整可能（設定に初期値を保存）

### F-06 書き出し
- 写真ライブラリへ保存（JPEG 高画質）
- 共有シート（AirDrop など）
- 元写真は変更しない

## 6. 非機能要件

| 区分 | 要件 |
|---|---|
| 操作時間 | 写真選択から保存まで1分以内（自動配置がうまくいけば30秒以内） |
| 処理場所 | すべて iPhone の中で処理。患者写真を外部へ送信しない |
| データ保持 | アプリ内に患者写真を残さない（作業中の一時データのみ） |
| オフライン | ネット接続なしで動作する |
| 画質 | 出力時に劣化させない |
| 使いやすさ | 説明なしで使える画面構成 |

## 7. 想定画面構成（案）

1. **写真選択**: 起動するとすぐ「4枚選ぶ」ボタン
2. **プレビュー・編集**: 2×2 の完成イメージ（自動配置・ブラー済み）。セルをタップして微調整、枠の入れ替え、ブラー ON/OFF
3. **保存**: 保存・共有
4. **設定**: 出力比率、ブラーの強さ・範囲の初期値

## 8. 確認事項（残り）

### 配布方式: Web アプリに決定
- Safari で開き「ホーム画面に追加」でアプリのように使う。期限切れ・再インストールなし、費用0円
- 写真は iPhone の中（ブラウザ内）で処理し、外部へ送信しない
- 顔検出は Google の MediaPipe（ブラウザ内で動く顔検出）を使う想定。アプリ本体と一緒に置き、初回読み込み後はオフラインでも動くようにする

### 決定事項
| # | 項目 | 決定 |
|---|---|---|
| 1 | アプリの置き場所 | GitHub（GitHub Pages で公開） |
| 2 | URL のアクセス制限 | なし（プログラムのみ公開。写真は含まない） |
| 3 | 保存の操作 | 「共有ボタン → 画像を保存」の1手間で問題なし |
| 4 | テスト用の写真 | 3人分（12枚）受領済み → `docs/02_テスト写真の分析.md` |
| 5 | 顔の大きさ・ブラーの強さ | 試作を見ながら決める（設定で後から変更可能） |

### 公開リポジトリでの注意
- 写真（テスト写真・サンプル）は `.gitignore` で除外し、絶対にコミットしない
